✂️ Moldes

Moldes de costura para ropa (con tus medidas) y peluches (desde un modelo 3D). Todo corre en tu navegador con Python.

Cargando Python… la primera vez puede tardar unos segundos.

¿Cómo preparo mi modelo en Blender?
  1. Modelá el peluche con formas suaves (sin detalles finos: eso va bordado).
  2. Opción A: separá cada pieza en un objeto (Edit Mode → seleccionar → P → Selection). Exportá con File → Export → Wavefront (.obj) marcando Object Groups.
  3. Opción B: marcá las costuras (Edge → Mark Seam), hacé UV → Unwrap y exportá con UV. Elegí "Por islas UV".
  4. Cada pieza tiene que poder abrirse plana: si es una esfera o un tubo, agregale costuras o pinzas. El programa te avisa cuánto se deforma cada pieza.
¿Cómo armo mi prenda? (guía y fórmulas)
  1. Medidas: creá las medidas que vas a pedir (por ejemplo cintura, cadera, largo_falda). Los nombres van sin espacios ni acentos.
  2. Variables (opcional): cuentas que usás varias veces, como Wq = (cadera + holgura) / 4.
  3. Puntos: trazá el molde como en papel. Empezá con un punto en (0, 0) y construí los demás con las herramientas: «desde otro punto» (→ x, ↓ y), «largo y ángulo», «sobre una línea», «punto medio», «cruce de dos líneas», «perpendicular», «a cierta distancia» (por ejemplo, el largo del hombro hasta tocar una línea) y «sobre una curva».
  4. Curvas: para escotes, sisas, tiros y costados. Bézier: inicio, control, control, fin. Suave: pasa por todos los puntos que le des.
  5. Piezas: en «contorno» escribí (o tocá en el dibujo) los puntos y curvas en orden alrededor de la pieza. Agregá doblez, hilo, piquetes con letras, pinzas (pata, vértice, pata) y márgenes especiales como el ruedo.
  6. Controles: verificá que las costuras que se unen midan lo mismo, por ejemplo largo(costado_e) - largo(costado_d).
  7. Probá cambiar las medidas: todo se recalcula. Cuando esté lista, Guardar la deja en «Mis prendas» y también aparece en la pestaña Ropa. Exportar baja un archivo .json para compartirla o usarla con python -m moldes personal.

En las fórmulas podés usar: + - * / ** ( ), decimales con punto (1.5), medidas y variables, A.x y A.y (coordenadas de un punto), dist(A, B), ang(A, B), largo(curva), largo(A, B, C), raiz(), sin() cos() tan() (en grados), asin() acos() atan() atan2(), min() max() abs(), redondear(x, 1), si(cintura > 80, 2, 1) y pi.

Atajos: rueda del mouse = zoom · arrastrar = mover el dibujo · con un campo activo, tocar un punto o curva lo escribe ahí · Ctrl+Z / Ctrl+Y = deshacer / rehacer (fuera de los campos) · al renombrar un punto se actualizan todas las fórmulas que lo usan.
