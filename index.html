✂️ Moldes

Moldes de costura para ropa (con tus medidas) y peluches (desde un modelo 3D). Todo corre en tu navegador con Python.

Cargando Python… la primera vez puede tardar unos segundos.

¿Cómo preparo mi modelo en Blender?
  1. Modelá el peluche con formas suaves (sin detalles finos: eso va bordado).
  2. Opción A: separá cada pieza en un objeto (Edit Mode → seleccionar → P → Selection). Exportá con File → Export → Wavefront (.obj) marcando Object Groups.
  3. Opción B: marcá las costuras (Edge → Mark Seam), hacé UV → Unwrap y exportá con UV. Elegí "Por islas UV".
  4. Cada pieza tiene que poder abrirse plana: si es una esfera o un tubo, agregale costuras o pinzas. El programa te avisa cuánto se deforma cada pieza.
